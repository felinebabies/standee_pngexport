# VQStandeeForge

分類別に手動出力した透過PNGをブラウザー内で合成し、宴4向けの全パターンをZIPへ書き出すデスクトップSPAです。画像データをサーバーへ送信せず、`.clip`やPSDは扱いません。

## 技術構成

- TypeScript + Vite
- Canvas / OffscreenCanvasによるRGBA合成
- IndexedDBによる画像込み自動保存
- fflateによるクライアント内ZIP生成
- Vitestによる決定的な組み合わせ列挙のテスト

React等のUIランタイムを使わず、MVPの配布サイズと依存範囲を小さくしています。

## 起動

```powershell
npm install
npm run dev
```

本番用ファイルは`npm run build`で`dist`へ生成されます。

## 基本操作

1. 左ペインで登録先グループを選び、`PNG登録`またはドラッグ&ドロップで透過PNGを追加します。
2. 左ペインの順序を変更し、右ペインで必須・任意、表示パーツ、使用禁止ペアを設定します。
   服などが下のパーツを完全に隠す場合は、そのパーツの「重複時に差分をまとめるグループ」で隠れるグループを指定します。
3. 中央のプレビューで有効な組み合わせを巡回します。
4. 出力量を最適化する前に構成を確認する場合は、`デバッグ用`メニューの`パターン組み合わせ数リスト`で画像を含まない診断用レポートを保存します。
5. `ZIP書き出し`で合成PNG、CSV、JSON、画像込みプロジェクト定義を生成します。

`パターン組み合わせ数リスト`には、件数の計算式、除外・重複抑制後の件数、全グループとパーツの有効状態、使用禁止ペア、重複抑制設定が含まれます。全パターンや画像データは列挙しないため、想定出力が多いプロジェクトでも小さいJSONファイルとして構成を共有・分析できます。

すべての入力PNGは同じキャンバス寸法である必要があります。元PNG、既存の`.clip`、PSDには変更を加えません。
